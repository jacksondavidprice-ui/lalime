# Write direct prose

Start with the subject and a useful answer at the reader's level. For a new
concept, say what it is, then what it does. Give each sentence a job: name the
kind, explain a fact, connect causes, supply evidence, or state a necessary
limit. Use ordinary words with precise meanings.

Use periods, commas, colons, or parentheses to connect thoughts. Write authored
prose without em dashes. Preserve punctuation inside exact code, commands,
identifiers, and source quotations. Quotation marks identify reproduced material;
keep your own explanation outside them.

Name the actor and action when the evidence identifies them. Keep passive voice
when the affected object is the subject the reader needs. Use technical terms
where they are more accurate, and explain unfamiliar ones on first use.

Use one stable name for each concept or component. Explain the connection when
introducing another name. Repeat an accurate term when it keeps the reference
clear. Choose wording for meaning rather than variation.

Support claims of importance with a concrete consequence. Attribute claims to
an identified source when attribution is needed. Express uncertainty at the
strength the evidence supports. Preserve useful contrasts and qualifications.

Keep the stated conditions, degree of certainty, and causal direction through
each edit. Add specificity only from evidence. State a missing detail when it
prevents a supported explanation. Personal experience and opinions require an
identified source or an explicit request to express a supported perspective.

Choose paragraph length and formatting for the information. Use a list for
parallel items, steps for a procedure, and a table for a comparison that needs
shared criteria. End when the question is answered.

Keep clear passages that already meet the reader's needs. Edit the part causing
confusion or violating the writing policy. Preserve a useful example, natural
cadence, and meaningful uncertainty. Let sentence length follow the reasoning.

Start with the subject itself. State the mechanism and its consequence directly.
Keep a contrast only when the distinction helps answer the question. Explain
importance through a specific effect. Use concrete actors and actions instead
of decorative descriptions. A sentence stays only if deleting it removes a
fact, cause, limit, or the example's result. Cut words that do no work. A
specific question that locates a reader's missing prerequisite can serve the
explanation.

Connect each paragraph to the question or the preceding reasoning. Use a general
statement when it explains a relationship needed here. Replace interchangeable
commentary with a supported fact or consequence, or omit it when it adds nothing.

Check the full answer for redundant explanations and repeated examples. Select
examples that expose the actual mechanism. Keep exact identifiers, commands,
quotations, citations, and numerical values intact unless evidence supports a
correction. Evaluate writing in context; individual words do not establish who
wrote a passage.

For each proposed style change, identify the loss of clarity, unsupported emphasis,
repetition, or writing-policy violation it fixes. Read the passage before deciding.
Keep a legitimate technical use or useful teaching device. After editing, check
that the repair preserved the meaning and resolved the actual problem.

These instructions extend the existing explanation skill and its evidence
policy. Phrase inventories remain in checker data outside the writer package.
