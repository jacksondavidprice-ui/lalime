# Submission notes (Jackson)

Deadline: **Mon Oct 26, 2026, 9:00pm ET (8:00pm CT)**. Aim to submit **Sun Oct 25**.

## One-sentence purpose (video)

Lalime lets anyone tell their computer what they need in plain English, then does it for them, without ever doing anything dangerous behind their back.

## Target audience

People who are not comfortable with computers — grandparents, parents, students — who today call a relative or pay for tech support.

## Tools and languages (say this in the video)

TypeScript, React, Electron, Tailwind CSS, a C# / .NET Hands helper, Guardian safety rules in TypeScript, and OpenAI Codex app-server for the live agent. Each person signs in with **their own ChatGPT account or API key** — there is no shared demo bot.

## AI disclosure line (video)

I used Cursor to move faster on the interface and plumbing, and I personally designed Guardian’s block rules and risk tiers so the AI never gets to decide what’s dangerous.

## Technical difficulty answer (draft — rewrite in your voice)

The hard part was not chatting with a model — it was making sure an agent that can click and run PowerShell cannot silently destroy a PC. I built Guardian as a fail-closed policy engine: a never-list, risk tiers, an optional reviewer that can only raise severity, plain-English approval cards, and Recycle-Bin undo. The product path is always the live Codex agent with the user’s own credentials.
