# Download Lalime (Windows)

**Get the app:** [Lalime-Setup-0.1.0.exe — latest release](https://github.com/jacksondavidprice-ui/lalime/releases/tag/v0.1.0-cac)

~224 MB · Windows 10/11 x64

## Install

1. Download `Lalime-Setup-0.1.0.exe` from the release above.
2. Run it. It isn't code-signed yet, so Windows SmartScreen shows "Windows protected your PC." Click **More info**, then **Run anyway**.
3. Open Lalime and connect an AI provider — Sign in with ChatGPT, or add your own API key in Settings. Once you get a real reply, it's connected.

Full install notes: [../docs/WINDOWS_INSTALL.md](../docs/WINDOWS_INSTALL.md)

The source code is in the rest of this repo. This folder is just the download and install guide.
